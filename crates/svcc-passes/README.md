# svcc-passes

Middle-end normalization and target-capability legalization passes for svcc-ir.

This crate is an internal part of [`svcc`](https://crates.io/crates/svcc) and is published
so that `svcc` can be installed from crates.io. Its API follows `svcc`'s needs and may change
in any 0.x release; depend on `svcc` instead.
