In ASIC verification, teams often write fast reference models and license-free testbenches in C++17 and IEEE 1666-2023 SystemC, while RTL sign-off and coverage closure still run in IEEE 1800-2023 SystemVerilog, IEEE 1800.2-2020 UVM, and SVA. Translating code across these two stacks by hand or with an unverified language model introduces quiet bugs: garbage-collected UVM handles clash with value-copied C++ transaction ports, SystemVerilog context-determined bit widths differ from C++ integer promotion, Preponed #1step sampling races against SystemC delta notifications, and large CRAVE constraint blocks trigger superlinear C++ template compile times.

This paper presents svcc, an open-source Rust compiler and translation-validation tool (12,600 lines of Rust across eight crates plus Python bindings) that translates in both directions between SystemVerilog (RTL and UVM testbench components) and C++17 SystemC 3.0.3 (IEEE 1666.1 RTL, UVM-SystemC, CRAVE, FC4SC, and untimed C++17 functions) through a seven-dialect IR (svcc-ir). Target passes clip and LCM-scale dist ranges, emit per-age cover counters, and generate a 32-bit Feistel randc engine. Every run is checked without commercial simulators by four solver gates: a Z3 QF_BV miter over constraints, enums, and dist support; bounded model checking of C++17 SVA observers; UCIS 1.0 isomorphism; and word-level Btor2 sequential equivalence checking across latency L >= 0. On a 20-design suite, svcc translates files in 272 us median (sv2sc) and 689 us median (sc2sv, with svlang-lint), proves 20/20 round-trip and 8/8 C-to-RTL checks in 5.37-21.68 ms, catches 20/20 injected bugs with 0/4 false alarms, recovers 12/12 standalone UVM/RAL files (vs. 4/12 semantic-only), cuts clang++ -O2 time at 120 clauses by 6.25x, cuts sliced-dist TVD by 60.8x, speeds up live CRAVE 10-bit randc by 341x, and lowers 9/12 OpenTitan/PULP/OpenHW/Ibex files.
